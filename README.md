# SplitSob

**SplitSob** adalah aplikasi mobile sederhana untuk menghitung pembagian biaya patungan bersama teman secara merata.

## Fitur Aplikasi
- Menambahkan dan menghapus peserta.
- Memasukkan nama dan total pengeluaran.
- Validasi input.
- Menghitung pembagian biaya secara otomatis.
- Menampilkan ringkasan patungan.
- Reset untuk membuat patungan baru.

## Bahasa dan Framework yang Digunakan
- Flutter
- Dart
